# CLAUDE.md

Agent notes for HiddenMeadowFarm/WinGetAutoUpdate-Blocklist. Read README.md for the human overview.

## Layout

- `excluded_apps.txt` is generated by `.github/workflows/build-blocklist.yml`. Never edit it by hand; edit `custom_blocklist.txt` (HMF-only) or the MVTS-Corp master list (all clients).
- Master list: `MVTS-Corp/WinGetAutoUpdate-Blocklist` on `main`. The workflow tries `excluded_apps.txt` first, then `blocklist.txt`, so either repo can rename first.
- Every entry is there because WAU auto-updating it caused a real problem. Do not remove entries without the user's approval. When adding one, put a `#` reason comment above it in `custom_blocklist.txt` and add a row to the "Why Each App Is Blocked" table in README.md.
- A repo with the same name exists under MVTS-Corp. Confirm which org you are working in before pushing.

## Gotchas (verified against WAU v2.12.0 source)

- WAU treats `WAU_ListPath` as a folder and requests `<WAU_ListPath>/excluded_apps.txt` (`Sources/Winget-AutoUpdate/functions/Test-ListPath.ps1`). The output file name is not negotiable. A file URL in `WAU_ListPath` makes every run exit with `White/Black List doesn't exist` on PCs with no local copy. This was the 2026-09/10 outage.
- raw.githubusercontent.com sends no `Last-Modified` header. Under Windows PowerShell 5.1, `[DateTime]$null` throws, so WAU falls into its catch path and re-downloads the list on every run. List edits do reach PCs (raw has a 5 minute cache).
- WAU's `Get-ExcludedApps` does not strip `#` lines. The workflow strips comments and blanks, so comments are fine in `custom_blocklist.txt` but must never be written into `excluded_apps.txt`.
- The `Winget-AutoUpdate` scheduled task reports success even when WAU fails. Use `logs\error.txt` on the PC.
- GitHub disables scheduled workflows after 60 days of repo inactivity (happened 2026-06-29). The workflow calls the enable API on each scheduled run to reset the timer; needs `actions: write`.

## Testing Workflow Changes

Extract the `run:` blocks and execute them locally with `bash -e`, with `MASTER_BASE` and `OUTPUT` exported, then diff the output against the published list (`diff --strip-trailing-cr` on Windows checkouts).
